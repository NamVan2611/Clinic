Overview

The Clinic Management System allows clinic staff and doctors to manage daily operations including:

Patient registration and medical history tracking

Appointment scheduling

Doctor dashboards

Prescription management

Administrative analytics

This project simulates a real healthcare SaaS product and showcases backend architecture, REST API design, authentication, and modern frontend development.
