# MediFlow Pro Frontend

A React + TypeScript + Tailwind CSS frontend scaffold inspired by the provided login page for MediFlow Pro.

## Getting started

```bash
cd frontend
npm install
npm run dev
```

Open the app at `http://localhost:5173`.

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```

## Notes

- The login page preserves the brand styling, palette, typography, spacing, and card layout from the original design.
- Client-side routing is handled with React Router.
- The app includes a sample dashboard to represent the production-ready user flow.
